# Skill: análisis de textos museográficos

Skill para Claude que guía el análisis de textos de museo (cédulas, catálogos, fichas) con el marco Ravelli / Halliday / Van Leeuwen.

- `SKILL.md`: instrucciones de la skill.
- `references/matrices.md`: matrices conceptual, analítica, operativa y de contexto.
- `references/clases-de-texto.md`: clasificación del texto por función.
- `references/flujo-codificacion.md`: de la precodificación a la revisión.
- `scripts/texto_clase.py`: ejemplo de clasificación (escrito para un corpus concreto; sirve como modelo).

No incluye datos ni textos de museos. Licencia MIT.
